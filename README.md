# 🛠️ Comanda+ Backend

API REST com NestJS, Prisma e PostgreSQL

## 🚀 Início Rápido

```bash
npm install
cp .env.example .env
npx prisma migrate dev
npx prisma db seed
npm run start:dev
```

Acesso: http://localhost:3001
